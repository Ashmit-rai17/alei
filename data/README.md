# data/

Empty in git on purpose. The pipeline writes everything here (or to `$ALEI_DATA`).

| file | contents | committed? |
|---|---|---|
| `manifest.csv` | archived URLs of the award compilations | no (regenerated by `discover`) |
| `pdfs/` | the 111 source PDFs | no |
| `inventory.parquet` | one row per PDF: pages, text, truncation flags | no |
| `awards.parquet` | **raw** award text: names, policy numbers, medical histories | **never** — it does not leave the machine |
| `awards_safe.parquet` | redacted award text | no — redaction is measured but not perfect |
| `label_sample.csv` | the 1,200 awards chosen for LLM labelling | no |
| `qwen_labels*.jsonl`, `labels.parquet`, `labels_rule.parquet` | labels with verbatim quotes from award text | no |
| `prashant/*.xlsx` | human-labelling sheets (contain award text) | no |
| `explorer.html` | the evidence explorer (embeds award text) | no |
| `corpus_stats.json`, `final_numbers.txt` | aggregate statistics | published as `docs/RESULTS.md` |
| `samples/sample_awards.txt` | 3 redacted awards, policy numbers masked | **yes** — the only award text in the repository |

Ombudsman awards are about real people's insurance disputes and health. What this project publishes
is structured fields and citations — award id, insurer, date, claim type, ground category and where
the supporting sentence is — not the text itself.
